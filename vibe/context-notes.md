# 컨텍스트 노트

## 2026-09-29 국립중앙박물관 릴스
- 수업 템플릿(reel.html)은 SPEC(JSON)만 바꾸면 되는 구조라, 템플릿 코드는 건드리지 않고 DEMO 값과 안내 문구만 교체했다.
- 문구는 사이트 원문만 썼다. 슬로건은 og:description "국립중앙박물관에 오신 것을 환영합니다", 관람시간·관람료·주소·전화는 메인 화면과 푸터 원문이다.
- 사진은 다운로드하지 않고 museum.go.kr 원본 주소를 그대로 참조한다. 오프라인이거나 사이트가 주소를 바꾸면 사진이 안 뜬다. 다운로드는 사용자 허락이 필요해서 하지 않았다.
- 사이트에 순수 유물 사진이 메인에 없어 배너·포스터 이미지를 쓴다. 배너에 글자가 박혀 있어 어두운 막을 씌운 장면에서도 글자가 비쳐 보인다.
- 전시 카드 5장은 이름과 포스터가 서로 맞는 것만 골랐다. 카드 이름 중 일부는 원문 제목의 앞부분만 줄여 썼다.
- 색상(네이비·청동·금)은 사이트 원문이 아니라 박물관 분위기에 맞춘 디자인 선택이다.
