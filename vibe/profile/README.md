## 👋 소개 (About)

안녕하세요. AI 기술창업과 정부 R&D 전략을 연구하고 교육하는 김종우입니다.

AI를 활용해 예비창업자와 중소기업의 아이디어를 사업모델로 구체화하고,
정부 R&D 과제로 기술을 검증해 사업화까지 연결합니다.

현장의 문제를 연구 주제로 발전시키고, 연구 결과를 교육과 실제 서비스에 적용합니다.

- **주요 활동:** AI 활용 교육 · 기술창업 컨설팅 · 정부 R&D 과제 기획 · 서비스 개발
- **협업 관심:** AI 서비스 기획, DX/AX, 중소기업 업무 자동화, 기술사업화, 실무 교육, AI 에이전트

## 🚀 대표 프로젝트 (Featured Projects)

### 와우그로스 — 정부지원사업 매칭 서비스

기업의 특성과 수요에 맞는 정부지원사업을 찾고, 사업 참여 준비를 지원하는 서비스입니다.

- **핵심 기능:** 공고 수집 → 문서 추출·분류 → 기업별 매칭 → 기업진단·보고서
- **참여 역할:** CTO · 기술 기획 및 개발
- **활용 기술:** Next.js, Supabase, Vercel, Gemini

### AI 트렌드 주간 브리핑 / AI 모닝 브리핑

AI 에이전트(닷, 뮤즈)를 활용하여 AI의 주요 변화를 정리하고, 국내 기업·기관의 활용과 R&D 기획에 필요한 인사이트를 제공합니다.

- **핵심 내용:** 주요 AI 동향, 핵심 변화, R&D 제안 인사이트
- **제공 형식:** 웹페이지 · PDF · PNG 인포그래픽
- **활용 기술:** GitHub, Vercel
- **서비스:** [AI 트렌드 주간 브리핑](https://ai-trend-weekly-coral.vercel.app/)

### 제조 공정·품질 개선 연구

제조 현장의 문제를 기술개발 목표와 측정 가능한 품질지표로 구체화합니다.

- **주요 주제:** Sheet Follower 기반 절곡 품질 개선
- **접근 방법:** 현장 문제 분석 → 개선 방안 설계 → 검증 → 사업화 연계

### AI 음성·교육 콘텐츠 사업화

AI 음성 기술을 방송·교육 콘텐츠에 적용하고,
아동교육용 동화·오디오북 창작 솔루션의 고도화와 사업화를 목표로 하는 프로젝트입니다.

- **주요 분야:** 음성합성, AI 콘텐츠 제작, 동화·오디오북, 외부 플랫폼 API 연동
- **핵심 R&D 프로젝트:** 아동교육 특화 AI 창작 솔루션
- **개발 방향:** 생성 콘텐츠의 사실 오류 검증, 캐릭터 일관성 유지, 텍스트·음성·이미지 연계
- **사업화 방향:** 교육기관용 구독 서비스와 출판사·교육 플랫폼 대상 API 공급
- **참여 역할:** 정부 R&D 과제 기획·사업모델 설계·사업화 전략 자문
