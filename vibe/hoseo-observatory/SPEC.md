# SPEC

## 프로젝트 이름

우면산 호서 천문대

## 목적

말없이 함께 멀리서 가끔 우는 부엉이 소리를 들으며 별을 보고 쉬는 웹 공간을 만든다.

기능을 많이 쓰는 도구가 아니라 머무는 곳이다. 조작은 적고 화면은 조용해야 한다. 이 성격이 이 문서의 모든 판단 기준이고, 기능을 더할지 망설여지면 빼는 쪽을 택한다.

## 사용자 흐름

1. 주소를 연다.
2. 인트로가 곧바로 시작된다. 태양계 → 지구 → 대한민국 → 서울시 서초구 우면산 정상의 우면산 호서 천문대 → 천문대 안 관측소 → 우면산에서 올려다본 하늘 순서로 넘어간다.
3. 천문대 화면에 도착한다. 내 캐릭터로 걸어 다니며 하늘을 보고, 같은 링크로 들어온 다른 사람의 캐릭터를 본다.
4. 첫 클릭이나 키 입력 뒤 곧 부엉이가 한 번 울고, 그 뒤로는 가끔 운다. 그 사이는 고요하다.

## 화면별 요구사항

### 인트로

- 접속하면 클릭 없이 곧바로 인트로가 시작된다.
- 태양을 중심으로 수성, 금성, 지구, 화성, 목성, 토성, 천왕성, 해왕성이 공전하고, 지구 주위를 달이 돈다.
- 이 장면에서 지구 → 대한민국 → 서울 → 서초구 → 우면산 → 우면산 호서 천문대로 천천히 줌 인하고, 단계마다 이름표가 나타난다.
- 지구본에는 대륙 윤곽을, 대한민국에서 우면산까지는 해안선, 서울 경계, 서초구 경계, 우면산 위치를 공개 지도 데이터로 그린다(출처는 CREDITS.md). 인트로 전체는 약 35초다.
- 이어서 천문대 안 관측소로 줌 인한 뒤 우면산에서 올려다본 하늘로 넘어간다.
- 화면 구석에 "건너뛰기" 버튼 하나를 둔다. 누르면 곧바로 천문대 화면으로 간다.
- 인트로 동안에는 소리가 나지 않는다.

### 천문대

공간과 이동

- 3D 공간이고, 내 캐릭터를 W·A·S·D 또는 방향키로 걷게 한다.
- 마우스를 끌어 보는 방향을 돌린다.
- 관측소 안에 망원경 1대가 있다.

천구

- 천구 가장자리에 동·서·남·북 글자 4개를 표시한다.
- 태양, 달, 행성 7개(수성, 금성, 화성, 목성, 토성, 천왕성, 해왕성)를 표시한다. 관측자가 지구 위에 서 있으므로 지구는 천구에 표시하지 않는다.
- 대표 별자리 12개를 별과 별을 잇는 선으로 표시한다. 오리온, 큰곰, 작은곰, 카시오페이아, 백조, 거문고, 독수리, 전갈, 사자, 쌍둥이, 황소, 페가수스다.
- 천체 위치는 접속한 현재 시각과 우면산 정상 좌표로 계산하고, 머무는 동안 시각이 흐르는 대로 갱신한다.
- 우면산 정상 좌표는 약 북위 37.465°, 동경 127.013°, 해발 293m로 둔다.
- 지평선 아래에 있는 천체는 회색으로 표시하고, 목록과 정보에 "지평선 아래"라고 적는다.

보기 방식과 고르기

- 보기 방식은 두 가지다. 맨눈으로 보는 천구, 그리고 망원경으로 보는 확대 모습이다.
- 천문대 화면에 처음 들어오면 맨눈 보기다.
- 망원경에서 2m 안으로 다가가면 "망원경으로 보기" 버튼이 나타나고, 멀어지면 사라진다.
- 망원경 보기에서는 고른 천체가 맨눈 보기보다 크게 보인다.
- 사용자가 고를 수 있는 것은 네 가지뿐이다. 눈으로 보기, 망원경으로 보기, 특정 별자리 보기, 특정 천체 보기.
- 별자리를 고르면 그 별자리가 화면 가운데로 온다.
- 천체를 고르면 그 천체가 화면 가운데로 오고, 이름, 방위각, 고도가 보인다.
- 화면 구성과 조작감은 Star Walk 2 같은 별자리 앱을 참고한다. 참고는 방식에 한정하고 디자인이나 자산을 베끼지 않는다.

소리

- 계속 나는 소리는 두지 않는다. 부엉이 소리(BigSoundBank #3459, #3460, CC0 중 하나)만 멀리서 들리듯 작게, 고음을 눌러 포근하게 울린다.
- 첫 울음은 소리가 시작되고 3~8초 뒤, 그 뒤로는 15~40초 사이 무작위 간격으로 계속 반복해 운다.
- 브라우저는 사용자 조작 전 자동 재생을 막는다. 그래서 소리는 접속 뒤 첫 클릭이나 첫 키 입력 때 시작한다.
- 소리가 시작되기 전에는 "클릭하면 소리가 납니다" 안내를 보여 주고, 소리가 시작되면 안내를 숨긴다.
- 소리 끄기·켜기 버튼 하나를 둔다.

### 함께 있기

- 같은 링크로 들어온 사람들이 서로를 캐릭터로 본다. 사이트 전체가 한 방이다.
- 캐릭터 위에 이름이 보인다.
- 다른 사람과 연결되지 않아도 혼자 보기는 그대로 되고, 오류 창은 띄우지 않는다.
- 나간 사람의 캐릭터는 10초 안에 사라진다.

이름

- 접속할 때마다 아래 20개 중 하나를 무작위로 붙인다. 모두 세상을 떠난 천체물리학자다.

```text
에드윈 허블, 칼 세이건, 베라 루빈, 헨리에타 스완 리빗, 수브라마니안 찬드라세카르,
아서 에딩턴, 세실리아 페인가포슈킨, 조르주 르메트르, 스티븐 호킹, 카를 슈바르츠실트,
애니 점프 캐넌, 프레드 호일, 한스 베테, 프리츠 츠비키, 에이나르 헤르츠스프룽,
헨리 노리스 러셀, 조지 가모프, 야코프 젤도비치, 낸시 그레이스 로먼, 제임스 진스
```

- 이름이 겹치면 나중에 들어온 쪽이 아직 안 쓰인 이름으로 다시 뽑는다. 들어온 시각이 같으면 연결 ID가 작은 쪽이 이름을 지킨다.
- 20개가 모두 쓰이고 있으면 "베라 루빈 2"처럼 번호를 붙인다.

인사

- "인사" 버튼 또는 G 키를 누르면 내 캐릭터가 1초 동안 고개를 숙인다.
- 같은 방의 모든 사람에게 그 동작이 보인다. 글자는 띄우지 않는다.
- 한 번 인사하면 3초 동안 다시 인사할 수 없다.

## 제외 범위

- 채팅
- 음성 대화
- 시각 바꾸기(과거·미래 하늘 보기)
- 로그인과 계정
- 이름 직접 고르기
- 방 만들기와 방 나누기
- 모바일 전용 조작
- 12개를 넘는 별자리, 성운과 은하 같은 깊은 하늘 천체

## 결정이 필요한 사항

사용자가 고른 결정 4개와, 이 문서를 쓰며 정한 사항을 적는다.

| 번호 | 사항 | 결정 | 이유 |
|---|---|---|---|
| D1 | 3D 구현 방식 | three.js를 이 프로젝트에 한해 예외로 허용한다. | 걸어 다니는 3D 공간을 순수 WebGL로 손수 짜면 코드가 길고 실습 난도가 크게 올라간다. vibe/CLAUDE.md의 "외부 라이브러리 금지"에 대한 예외는 이 프로젝트에만 둔다. |
| D2 | 다중 접속 방식 | Trystero를 이 프로젝트에 한해 예외로 허용한다. | 내 서버 없이 WebRTC로 브라우저끼리 직접 연결해 GitHub Pages 공개와 "서버 없음" 규칙을 지킨다. 처음 만날 때만 공개 중계를 쓴다. |
| D3 | 같은 링크의 범위 | 사이트 전체가 한 방이다. | 방 이름을 만들고 나누는 조작이 생기지 않아 "조작은 적게"와 맞는다. |
| D4 | 소리의 출처 | CC0 녹음 파일을 저장소에 넣어 반복 재생한다. | 합성음보다 사실적이다. 파일마다 출처와 라이선스를 기록한다. |
| D5 | 라이브러리 파일 위치 | three.js와 Trystero는 버전을 고정한 파일을 저장소 `vendor/`에 넣는다. | CDN 장애나 버전 변경에 흔들리지 않는다. 버전은 구현 단계에서 Context7로 최신 문서를 확인하고 정한다. |
| D6 | 천구의 지구 | 표시하지 않는다. | 관측자가 지구 위에 서 있다. |
| D7 | 소리 시작 시점 | 첫 클릭이나 첫 키 입력 때 시작한다. | 브라우저가 사용자 조작 전 자동 재생을 막는다. |
| D8 | 인트로 건너뛰기 | 버튼 하나를 둔다. | 다시 들어오는 사람이 매번 인트로를 기다리지 않게 한다. |
| D13 | 소리 구성 | "Campaign at night #1" 하나만 쓴다. | 바람과 풀벌레 녹음을 들어 보니 귀에 거슬렸고, 가장 고요한 한 트랙만 둔다(2026-11-12 사용자 결정). |
| D14 | 부엉이 소리 | 밤 들판 소리 위에 부엉이 한 마디를 불규칙하게 더한다. 밤 들판 소리 음량은 절반으로 낮춘다. | 계속 나는 소리 없이도 밤 산의 느낌을 주고, 더 조용하게 하기 위해서다(2026-11-12 사용자 결정). D15로 바뀌었다. |
| D15 | 소리 구성(최종) | 밤 들판 소리를 빼고 부엉이 소리만 둔다. D13, D14를 대신한다. | 밤 들판 녹음의 풀벌레 소리도 귀에 거슬렸다. 부엉이 사이의 고요가 이 공간의 성격에 맞는다(2026-11-12 사용자 결정). |

| R3 | 행성이 태양 주위를 공전한다. | 화면 확인: 5초 지켜보면 행성들의 위치가 바뀐 것이 보인다. |
| R4 | 달이 지구 주위를 돈다. | 화면 확인: 5초 지켜보면 지구 옆 달의 위치가 바뀐 것이 보인다. |

| R6 | 천문대 다음에 관측소, 그다음 하늘로 넘어간다. | 화면 확인: 천문대가 보인 뒤 관측소 내부가 보이고, 이어서 하늘 화면으로 바뀐다. |
| R7 | 건너뛰기로 인트로를 넘길 수 있다. | 화면 확인: 인트로 중 건너뛰기를 누르면 곧바로 천문대 화면이 보인다. |
| R8 | 내 캐릭터가 키보드로 걷는다. | 화면 확인: W·A·S·D나 방향키를 누르면 내 캐릭터가 그쪽으로 걸어간다. |
| R9 | 마우스로 보는 방향을 돌린다. | 화면 확인: 마우스를 끌면 보이는 하늘이 끈 방향으로 돈다. |
| R10 | 천구에 방위 글자 4개가 있다. | 화면 확인: 한 바퀴 돌아보면 동·서·남·북 글자 4개가 보인다. |
| R11 | "북" 방위가 실제 북쪽이다. | Stellarium Web 비교: 같은 시각 우면산 좌표 화면처럼 "북" 글자 위쪽 하늘에 북극성이 보인다. |
| R12 | 천체 목록에 지구를 뺀 9개 천체가 있다. | 화면 확인: 천체 목록을 열면 태양, 달, 수성, 금성, 화성, 목성, 토성, 천왕성, 해왕성 9개가 보인다. |

| R16 | 별자리가 별을 잇는 선으로 그려진다. | 화면 확인: 오리온자리를 고르면 그 별들을 잇는 선이 보인다. |

## 수동 확인

`hoseo-observatory/index.html`을 브라우저로 열어 다음을 확인한다. 이 파일은 아직 없다.

- R1~R42의 확인 열을 차례로 수행한다.
- 다중 접속 기준(R33~R36, R38, R40)은 같은 링크로 브라우저 창 두 개를 열어 확인한다.
- 천체 위치 기준(R11, R13, R14, R17, R19)은 Stellarium Web을 우면산 좌표와 같은 시각으로 맞춰 비교한다.

## 남은 위험

- 우면산 정상 좌표(약 북위 37.465°, 동경 127.013°, 해발 293m)는 지도에서 다시 확인해야 한다.
- three.js와 Trystero 예외로 vibe/CLAUDE.md의 "외부 라이브러리 금지"와 이 프로젝트의 규칙이 다르다. 다른 실습에 예외가 번지지 않게 해야 한다.
- Trystero는 처음 만날 때 공개 중계를 쓴다. 중계가 막히거나 회사·학교 망이 WebRTC를 막으면 서로를 보지 못한다.
- 사이트 전체가 한 방이라 모르는 사람과도 함께 있게 된다. 사람이 많아지면 연결 수가 늘어 느려질 수 있다.
- 이름이 겹칠 때 다시 뽑는 규칙은 두 사람이 거의 동시에 들어오면 잠깐 같은 이름이 보일 수 있다.
- CC0 녹음 파일의 출처와 라이선스 기록이 빠지면 공개할 때 문제가 된다.
- 부엉이가 15~40초에 한 번만 울어서, 그 사이에는 소리가 켜져 있는지 귀로 알기 어렵다. 소리 버튼 글자("소리 끄기")로만 알 수 있다.
- R13, R14, R17, R19의 2° 허용 범위가 계산 방식(대기 굴절 반영 여부 등)에 따라 넘칠 수 있다.
- 저사양 노트북과 모바일 브라우저에서의 3D 속도는 확인 대상이 아니다.
