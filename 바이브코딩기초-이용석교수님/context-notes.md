## 위험하고 모호한 부분

1. **localStorage 가용성**
   `file://`로 열 때 브라우저에 따라 저장이 막히거나 도메인 구분이 달라질 수 있다. 실제 동작을 확인하기 전에는 보장하지 않는다. 2단계에서 직접 확인한다.
2. **`id` 생성 방식 미정**
   `crypto.randomUUID()`는 `file://` 같은 비보안 컨텍스트에서 막힐 수 있다. 시간값+난수 같은 단순한 방식을 후보로 두고 2단계에서 정한다.
3. **카테고리 탭과 추가 입력의 관계 미정**
   "공부" 탭을 보는 중에 추가하면 기본 카테고리를 탭에 맞출지 PRD에 없다. 제안은 입력창의 카테고리 선택 값을 그대로 쓰고 탭은 건드리지 않는 것이다.
4. **수정 UI 방식 미정**
   목록 안에서 바로 편집할지 별도 입력창을 쓸지 PRD에 없다. 제안은 항목 안에서 제목 입력칸과 카테고리 선택으로 바뀌는 인라인 편집이다. 브라우저 기본 팝업창(`prompt`)은 쓰지 않는다.
5. **삭제 확인 여부 미정**
   삭제 시 확인 단계를 둘지 PRD에 없다. 제안은 확인 없이 삭제이다. 항목이 작고 개인용이기 때문이다. 실수가 잦다면 나중에 실행취소를 고려한다.
6. **카테고리별 진행률에서 항목이 0개인 경우**
   0/0이면 "0/0"으로 표시하고 퍼센트는 계산하지 않는다(0으로 나누기 방지).
7. **PRD와 PROMPTS의 단계 번호 차이**
   `PROMPTS.md`는 계획을 1단계, 검증을 5단계로 센다. 이 체크리스트는 계획을 0단계로 두어 번호가 하나씩 다르다. 내용은 동일하다.
