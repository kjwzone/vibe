# 문항별 정답률 분석

학생 결과 파일의 문항별 정답 여부로 어떤 문제를 많이 틀렸는지 분석한다. **파일을 바꾸지 않는다.**

## 데이터 출처

- `class-results/*.json` 학생 결과 파일 (`/teacher-collect`와 같은 검사를 통과한 기록만). 다른 폴더는 인수로: $ARGUMENTS
- 문제 본문과 정답은 `src/data/questions.json`

## 실행

```bash
node .claude/skills/teacher-collect/class.mjs questions [폴더]
```

- 수집 결과 다음에 문항별 표(문항, 분야, 정답률, 정답/시도, 문제, 정답)를 정답률 낮은 순으로 출력한다. 앱 선생님 모드의 "문항별 정답률"과 같은 순서다.
- 마지막 줄에 **정답 오류 의심** 문항을 출력한다. 정답률 30% 미만이면서 시도 3회 이상인 문항이다.

## 의심 문항 점검

정답률이 낮은 이유는 "어려운 문제"일 수도 있고 "정답이 틀린 문제"일 수도 있다. 의심 문항마다 `/quiz-check` 스킬의 2장(정답 점검)과 4장(모호한 표현) 기준으로 확인한다.

- 정답·해설이 맞고 표현도 분명하면: "어려운 문항"으로 분류하고 수업에서 다룰 개념을 한 줄로 적는다.
- 정답이 틀렸거나 정답이 둘 이상이면: "정답 오류"로 보고한다. 고치지는 않는다(`/quiz-add`, `/quiz-check`의 승인 절차를 따른다).
- 확신할 수 없으면: "확인 필요"로 보고한다.
