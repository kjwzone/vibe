# 게임·선생님 모드 회귀 검증

코드나 문제 데이터를 바꾼 뒤 기존 게임과 선생님 모드가 모두 동작하는지 확인한다. `npm run build`가 `dist/`를 다시 만들기 때문에 파일을 바꾸는 스킬로 분류한다.

## 데이터 출처

- 소스 코드(`src/`), 문제 은행(`src/data/questions.json`), 빌드 결과(`dist/index.html`)
- 스모크 테스트는 임시 브라우저 프로필에서 실행한다. 사용자의 실제 브라우저 기록(`quiz_leaderboard`)은 건드리지 않는다.

## 순서

각 단계가 실패하면 **다음 단계로 가지 말고** 실제 출력(실패한 테스트 이름, 오류 메시지)을 그대로 보고한다.

1. `npm test`: 전체 단위 테스트. `teacher.test.ts`(결과 파일 검사, 집계, CSV)와 `gameReducer.test.ts`(선생님 모드 열기·닫기) 포함
2. `npm run lint`: 경고도 보고한다. 화면 컴포넌트에서 `new Date()`를 직접 부르면 경고가 나므로 lib 함수로 옮긴다(D28)
3. `npm run build`: 타입 검사와 `dist/index.html` 생성
4. `node .claude/skills/teacher-verify/smoke.mjs`: 빌드된 `dist/index.html`을 headless Chrome(360×800)으로 열어 아래 14개 항목을 확인한다

| 구분 | 확인 항목 |
| --- | --- |
| 기존 게임 | 시작 화면 버튼, 키보드(1~4, Enter)로 40문제 완주, 순위 등록, 새로고침 후 순위표 유지, 360px 가로 넘침 없음(시작·결과) |
| 결과 제출 | 빈 이름 거부, 결과 파일 저장(문항 40개, 점수 일치) |
| 선생님 모드 | 파일 3개 불러오기(학생 2명 행, 문항 40행), 깨진 파일 오류 표시, 360px 페이지 넘침 없음, CSV(BOM, 머리글 + 2행), 돌아가기 |

- Chrome/Edge가 없으면 스모크 테스트는 `오류:`로 끝난다. 이 경우 1~3단계 결과와 함께 "브라우저 확인 미실시"로 보고하고, 사람이 확인할 절차(위 표)를 안내한다.
