# 상식 퀴즈 게임 PRD

Oct 30, 2026 · @Jong-woo Kim

## 1. 개요

한국사·과학·지리·일반상식 4개 분야 40문제를 4지선다로 풀고, 문제마다 즉시 정답/오답 피드백을 받으며, 최종 점수와 순위를 남기는 웹 기반 상식 퀴즈 게임이다.

| 항목 | 내용 |
| --- | --- |
| 제품명 | 상식 퀴즈 게임 (가칭) |
| 플랫폼 | 웹 브라우저 (PC·모바일 반응형), 로그인 없음 |
| 한 판 구성 | 4개 라운드 × 10문제 = 40문제, 약 10분 |
| 핵심 가치 | 짧은 시간에 4개 분야 상식 점검 + 즉시 해설로 학습 + 순위로 재도전 동기 |
| 1차 릴리스(MVP) | 40문제 풀코스 모드, 즉시 피드백, 결과 화면, 기기 내 순위표 Top 10 |
| 문서 버전 | v0.1 초안 — 11장 오픈 이슈 확정 후 v1.0 |

## 2. 목표와 성공 지표

1차 목표는 40문제를 '끝까지 푸는 경험'이며, 핵심 지표는 완주율 60% 이상이다.

1. 재미: 즉시 피드백과 진행 표시로 40문제 완주를 유도한다.
2. 학습: 문제마다 해설을 보여 틀린 지식을 바로 보완한다.
3. 재도전: 점수·순위 기록으로 반복 플레이를 유도한다.

| 지표 | 정의 | 목표 (출시 후 4주) |
| --- | --- | --- |
| 완주율 | 결과 화면 도달 세션 ÷ 게임 시작 세션 | 60% 이상 |
| 재플레이율 | 2회 이상 플레이한 사용자 ÷ 전체 사용자 | 30% 이상 |
| 평균 플레이 시간 | 1번 문제 표시 \~ 결과 화면 도달 | 8\~12분 |
| 순위 등록률 | 닉네임 등록 ÷ 결과 화면 도달 | 50% 이상 |
| 문제 오류 | 정답·해설 오류 확인 건수 | 0건 (출시 전 교차검수) |

목표치는 제안값이며 첫 2주 실측 후 조정한다.

## 3. 대상 사용자와 사용 시나리오

핵심 사용자는 스마트폰으로 10분 안팎을 즐기는 성인·대학생이고, 수업·워크숍에서 화면을 띄워 함께 푸는 진행자가 2차 사용자다.

| 사용자 | 상황 | 핵심 니즈 | 관련 기능 |
| --- | --- | --- | --- |
| 캐주얼 플레이어 (20\~40대) | 출퇴근·휴식 시간, 모바일 | 가볍게 상식 점검, 점수 비교 | 진행 표시, 결과 화면, 순위표 |
| 학생·수험생 | 한국사·과학 복습 | 틀린 이유 확인, 약한 분야 파악 | 즉시 해설, 카테고리별 점수, 오답 노트(P1) |
| 진행자 (강사·교사) | 수업 도입부 아이스브레이킹, PC 화면 공유 | 함께 풀며 분위기 전환 | 큰 글씨 보기, 키보드 1\~4 선택 |

대표 시나리오: 사용자가 시작 화면에서 \[게임 시작\]을 누르고, 라운드별 10문제를 풀며 문제마다 해설을 확인한 뒤, 결과 화면에서 닉네임을 입력해 순위표에 이름을 올린다.

## 4. 게임 규칙

한 판은 4개 라운드(카테고리) × 10문제 = 40문제이며, 정답 1문제당 10점으로 400점 만점이다.

| 규칙 | 정의 |
| --- | --- |
| 문제 형식 | 4지선다 객관식, 정답은 1개 |
| 카테고리 | 한국사, 과학, 지리, 일반상식 |
| 출제 수 | 카테고리별 10문제, 총 40문제 |
| 진행 순서 | 라운드 1 한국사 → 2 과학 → 3 지리 → 4 일반상식 (라운드 안의 문제 순서·보기 순서는 무작위) |
| 답 선택 | 1회 선택 즉시 확정, 변경 불가 |
| 피드백 | 선택 즉시 정답/오답 표시 + 정답 보기 강조 + 해설 1\~2문장 |
| 점수 | 정답 10점, 오답 0점, 감점 없음 |
| 제한시간 | MVP 없음 (P1: 문제당 20초 타이머 모드) |
| 종료 | 40번째 문제의 피드백 확인 후 결과 화면으로 이동 |
| 순위 기준 | 총점 높은 순, 동점이면 소요시간 짧은 순 (7장) |

| ID | 기능 | 설명 | 우선순위 | 수용 기준 |
| --- | --- | --- | --- | --- |
| F-01 | 시작 화면 | 게임 소개, 규칙 요약, \[게임 시작\]·\[순위표\] 버튼 | P0 | 첫 화면에서 1번 탭으로 게임 시작 |
| F-02 | 문제 출제 | 카테고리별 10문제 로드, 문제·보기 순서 무작위 | P0 | 한 게임 안에서 중복 문제 0건, 섞은 뒤에도 정답 판정 정확 |

| F-04 | 답 선택·잠금 | 보기 선택 즉시 확정, 이후 보기 비활성화 | P0 | 연타해도 점수 1회만 반영 |

| F-08 | 순위 기록 | 닉네임 입력·저장, Top 10 순위표, 내 기록 강조 | P0 | 새로고침 후에도 기록 유지 |
| F-09 | 다시 하기 | 결과 화면에서 새 게임 시작 | P0 | 점수·진행·타이머 모두 초기화 |

| F-13 | 효과음 | 정답·오답 사운드, 음소거 토글 | P2 | 음소거 설정 유지 |

| F-15 | 온라인 순위표 | 서버 저장, 전체 사용자 순위 | P2 | 서버 검증된 점수만 등록 |

## 7. 점수·순위 시스템

순위는 총점 내림차순 → 소요시간 오름차순 → 기록 시각 오름차순으로 정하며, MVP는 브라우저(localStorage)에 최대 50건을 저장하고 Top 10을 보여준다.

- 총점 = 정답 수 × 10 (0\~400점)
- 정답률 = 정답 수 ÷ 40 × 100 (%)
- 소요시간 = 1번 문제 표시 \~ 40번 문제 답 선택 (초 단위, 해설 읽는 시간 포함)

| 등급 | 총점 |
| --- | --- |
| 상식 마스터 | 360\~400점 |
| 상식 고수 | 280\~350점 |
| 상식 중수 | 200\~270점 |
| 상식 입문 | 0\~190점 |

순위 기록 데이터:

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| nickname | string | 2\~10자, 공백만 입력 불가 |
| score | number | 총점 (0\~400) |
| correctCount | number | 정답 수 (0\~40) |
| categoryScores | object | 카테고리별 점수 (각 0\~100) |
| durationSec | number | 소요시간(초) |
| playedAt | string | 기록 시각 (ISO 8601) |

- 저장 키: `quiz_leaderboard`, 50건 초과 시 순위가 가장 낮은 기록부터 삭제
- 방금 등록한 기록은 순위표에서 강조하고, Top 10 밖이면 '내 순위 N위'를 따로 표시
- localStorage를 쓸 수 없는 환경(사생활 보호 모드 등)에서도 게임은 정상 진행, 순위 저장만 생략하고 안내 문구 표시

## 8. 콘텐츠·데이터 요구사항

MVP는 카테고리별 10문제(총 40문제) 문제 은행으로 동작하고, 재플레이 다양성을 위해 v1.1에서 카테고리별 30문제(총 120문제)로 늘려 매 게임 10문제씩 무작위 추출한다.

| 필드 | 타입 | 필수 | 설명 | 예시 |
| --- | --- | --- | --- | --- |
| id | string | Y | 고유 ID (카테고리 접두어 + 번호) | HIS-001 |
| category | enum | Y | history / science / geography / general | history |
| question | string | Y | 문제 본문, 80자 이내 | 훈민정음을 창제한 조선의 왕은? |
| options | string\[4\] | Y | 보기 4개, 각 20자 이내 | 태조, 태종, 세종, 정조 |
| answerIndex | number | Y | 정답 보기 위치 (0\~3, 원본 기준) | 2 |
| explanation | string | Y | 해설 1\~2문장 | 세종이 1443년 창제하고 1446년 반포했다. |
| difficulty | enum | N | easy / normal / hard | easy |
| source | string | N | 검수 근거 출처 | 교과서·백과사전 항목명 |

카테고리별 샘플 문제:

| 카테고리 | 문제 | 보기 | 정답 |
| --- | --- | --- | --- |
| 한국사 | 훈민정음을 창제한 조선의 왕은? | 태조 / 태종 / 세종 / 정조 | 세종 |
| 과학 | 물의 화학식은? | CO2 / H2O / O2 / NaCl | H2O |
| 지리 | 세계에서 면적이 가장 넓은 나라는? | 캐나다 / 중국 / 미국 / 러시아 | 러시아 |
| 일반상식 | 올림픽 오륜기의 고리는 모두 몇 개인가? | 4개 / 5개 / 6개 / 7개 | 5개 |

```json
{
  "id": "HIS-001",
  "category": "history",
  "question": "훈민정음을 창제한 조선의 왕은?",
  "options": ["태조", "태종", "세종", "정조"],
  "answerIndex": 2,
  "explanation": "세종이 1443년 창제하고 1446년 반포했다.",
  "difficulty": "easy"
}
```

문제 검수 체크리스트 (출시 전 전 문항 적용):

- [ ] 정답이 하나뿐인지 2인 교차검수
- [ ] 보기 길이·형식을 비슷하게 맞춤 (정답만 길면 힌트가 됨)
- [ ] '모두 정답', '정답 없음' 보기 사용 금지
- [ ] 인구·현직 인물처럼 시점에 따라 바뀌는 사실은 제외하거나 기준 시점 명시
- [ ] 정치·종교 등 논쟁적 소재 제외
- [ ] 라운드별 난이도 분포 쉬움 4 · 보통 4 · 어려움 2 (권장)
- [ ] 생성형 AI로 만든 문제는 source 필드에 근거를 적고 사람이 최종 확인

## 9. 비기능 요구사항

MVP는 서버 없이 정적 웹으로 동작하고, 모바일 360px 폭과 색약 사용자까지 문제없이 플레이할 수 있어야 한다.

| 구분 | 요구사항 |
| --- | --- |
| 지원 환경 | 최신 Chrome·Safari·Edge, 모바일 360px 폭 이상 |
| 성능 | 첫 화면 로드 2초 이내(4G 기준), 답 선택 후 피드백 0.3초 이내 |
| 접근성 | 색상만으로 정·오답 구분 금지(O/X 텍스트 병행), 명도 대비 4.5:1 이상, 키보드 1\~4로 보기 선택·Enter로 다음 |
| 구조 | 정적 웹(서버·DB 없음), 문제 은행은 JSON 파일 1개 |
| 개인정보 | 닉네임 외 개인정보 수집 없음, 쿠키·분석 도구는 MVP에서 제외 |
| 상태 보존 | 게임 중 새로고침 시 진행 복원 (P1) |
| 언어 | 한국어 단일 |
| 품질 | 점수 계산·순위 정렬 로직 단위 테스트 필수 |

## 10. 범위와 마일스톤

MVP는 P0 9개로 2주 안에 출시하고, v1.1(+2주)과 v2(+4주)는 각 게이트 기준을 넘을 때만 착수한다. 기간은 1인 개발 기준 제안값이다.

&#91;embedded content: 릴리스 로드맵 · 3단계, 게이트 2개\]

서버가 필요한 온라인 순위표(v2)는 게이트 2의 완주율·재플레이율이 확인된 뒤에만 투자한다.
