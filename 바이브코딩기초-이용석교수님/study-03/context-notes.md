# 컨텍스트 노트 상식 퀴즈 게임

작업 중 내린 결정과 그 이유를 기록한다. 새 결정은 아래에 계속 덧붙인다.

## 결정

| # | 결정 | 이유 |
|---|------|------|
| D1 | 기준 문서는 `상식 퀴즈 게임 PRD.md`. 파일명은 바꾸지 않음 | 프롬프트는 `PRD.md`라고 부르지만 실제 파일명이 다름. 이름 변경은 요청받지 않았음. |
| D2 | 기술 스택은 Vite + React + TypeScript + Vitest | 3단계 프롬프트 문서의 기본값. 사용자가 1단계 프롬프트에서 그대로 지정함. |
| D3 | 프로젝트는 `study-03/` 바로 아래에 생성 | 이 폴더가 저장소의 작업 단위이고 기획 문서가 이미 있음. 상위 폴더의 할 일 앱과 섞이지 않게 함. |
| D4 | create-vite는 임시 폴더에서 실행한 뒤 파일을 복사 | `study-03/`가 비어 있지 않아 대상 지정 시 덮어쓰기 프롬프트가 나옴. 기존 문서를 지울 위험을 피함. |
| D5 | 체크리스트·컨텍스트 노트·의미 단위 커밋 진행 (푸시 안 함) | 사용자 승인. 프로젝트 CLAUDE.md의 7번, 9번 규칙. |
| D6 | 작업 시작 전 Context7로 Vite, Vitest 문서 확인 | 사용자 전역 지침. 비대화형 생성은 `npm create vite@latest <이름> -- --template react-ts`, Vitest 설정은 `vite.config.ts`의 `test` 블록. |
| D7 | 보기 길이·개수 제한(문제 80자, 보기 20자)도 테스트로 검증 | PRD 8장 스키마 제한. 문제 추가 시 어긴 문항을 바로 잡기 위함. |
| D8 | 섞기 함수는 난수 함수를 인자로 받음 (기본값 `Math.random`) | 테스트에서 시드 고정 난수를 넣어 결과를 재현하기 위함. |
| D9 | 정답이 둘로 해석될 수 있는 소재는 문제에서 제외 | 가장 긴 강(나일·아마존), 적도 통과국(브라질 등)처럼 기준에 따라 답이 달라지는 사실은 PRD 8장 검수 항목에 어긋남. |
| D10 | 시점에 따라 바뀌는 사실(인구, 현직 인물 등)은 제외 | PRD 8장 검수 항목. 기생충 작품상(2020년)처럼 고정된 과거 사실만 사용. |
| D11 | 기본 예제 코드(App.css, assets, icons.svg)를 지우고 `App`은 빈 `<main />` | 1단계는 빈 화면이 완료 기준. 게임 화면은 2단계에서 만듦. |
| D12 | `README.md`는 Vite 기본 내용 그대로 둠 | 3단계 할 일(README 작성)에서 다룸. 지금 바꾸면 범위를 벗어남. |
| D13 | 4라운드가 끝나면 라운드 결과 화면 없이 바로 결과 화면으로 이동 | 사용자 승인(기본값). PRD 4장 "40번째 문제 피드백 후 결과 화면". 결과 화면에 분야별 점수가 있음. |
| D14 | 소요시간은 START 시각 ~ 40번째 답 선택 시각 | 사용자 승인(기본값). PRD 7장. 시각은 액션에 담아 reducer를 순수하게 유지하고 테스트에서 고정함. |
| D15 | [다시 하기]는 `START` 액션으로 새 문제를 섞어 바로 새 게임 시작 | 점수·진행·시간이 모두 초기화되어야 함(F-09). 시작 화면을 거치지 않아 한 번 덜 누름. |
| D16 | 연타 방지는 reducer에서 처리 (`phase`가 playing이 아니면 ANSWER 무시) | 버튼 비활성화는 렌더 이후에야 적용되므로 클릭과 키 입력이 겹치면 뚫릴 수 있음. 상태 기준으로 막으면 어떤 입력 경로도 안전함. |
| D17 | Enter는 `keydown`에서 `preventDefault` 후 `event.repeat`이면 무시 | 포커스된 [다음] 버튼이 키 반복으로 계속 클릭되어 라운드 결과 화면을 건너뛰는 것을 막음. |
| D18 | 화면 디자인은 시험 답안지(OMR) 모티프, 글꼴은 시스템 한글 글꼴 | 보기 번호 1~4와 키보드 입력이 맞아떨어짐. 웹폰트를 쓰지 않아 첫 화면 2초 요구(PRD 9장)에 유리함. |
| D19 | 시작 화면의 [순위표] 버튼은 3단계에서 추가 | 사용자 지시. 순위 저장은 2단계 범위 밖. |
| D20 | 스타일은 라이브러리 없이 `src/index.css` 한 파일 | 화면이 4개뿐이라 분리할 이유가 없음. |
